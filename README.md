# Помічник з документами

iPhone-застосунок (React Native + Expo, TypeScript) для нагадувань про строки документів.
Опис проєкту — у `CLAUDE.md`, вигляд — у `prototype.html`, план — у `plan.pdf`.

## Статус: етап 2 (основа) — розпочато
Готово: екрани «Вітання» і «Мої документи» з тестовими даними, українська/польська (перемикач UA/PL на вітанні).
Ще не зроблено: збереження в SQLite, Face ID, інші екрани.

## Як подивитись у браузері
```bash
npm install
npm run web
```
Відкрий http://localhost:8081. Для вигляду телефона натисни F12 → іконка телефона.

## Структура
- `App.tsx` — шрифти, мова, перемикання екранів
- `src/screens/` — екрани
- `src/components/` — кільце, іконки, анімації
- `src/data/documentTypes.ts` — типи документів (новий тип додається тут + переклади в `src/i18n.tsx`)
- `src/data/testDocuments.ts` — тестові дані
- `src/lib/status.ts` — дні, статуси (терміново ≤30, скоро 31–60, в порядку >60)
