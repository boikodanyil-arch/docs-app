# Помічник з документами

iPhone-застосунок (React Native + Expo, TypeScript) для нагадувань про строки документів.
Опис проєкту — у `CLAUDE.md`, вигляд — у `prototype.html`, план — у `plan.pdf`.

## Статус: етап 2 готовий, починаємо етап 3
Працює: вітання, мої документи (SQLite на телефоні), сканування (камера / галерея / вручну), перевірка даних,
картка документа (редагування, видалення, календар), нагадування за 60/30/7 днів (локальні пуші),
Face ID / код, українська й польська, ліміт 3 документи і пейвол.

Ще не зроблено:
- **Розпізнавання тексту (OCR)** — потрібна development build; зараз дані вводяться вручну (`src/lib/ocr.ts`).
- **Оплата через App Store** — пейвол є, але покупки не підключені (етап 5); для тесту є «Тестовий режим» в налаштуваннях.

## Як подивитись у браузері
```bash
npm install
npm run web
```
Відкрий http://localhost:8081. Для вигляду телефона натисни F12 → іконка телефона.

## Перевірка коду
```bash
npm test          # автотести (дати, статуси, парсер тексту документів)
npm run typecheck # перевірка типів
```

## Структура
- `App.tsx` — шрифти, мова, перемикання екранів
- `src/screens/` — екрани
- `src/components/` — кільце, іконки, анімації
- `src/data/documentTypes.ts` — типи документів (новий тип додається тут + переклади в `src/i18n.tsx`)
- `src/data/store.ts` (SQLite) і `store.web.ts` (браузер) — збереження
- `src/lib/parseDocumentText.ts` — пошук типу й дат у тексті (для OCR), покритий тестами
- `src/lib/reminders.ts` — локальні нагадування; `src/lib/ocr.ts` — місце для OCR
- `src/data/testDocuments.ts` — тестові дані (кнопка в налаштуваннях)
- `src/lib/status.ts` — дні, статуси (терміново ≤30, скоро 31–60, в порядку >60)
